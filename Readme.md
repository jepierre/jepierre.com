# jepierre.com

Tutorials for Using Jekyll:

## Install Guide

Install Ruby via [RubyInstaller](https://rubyinstaller.org/)

[How to install Jekyll on windows](https://jekyllrb.com/docs/installation/windows/)

## Run site

instlal the jekyll and bundler gems

```
gem install jekyll bundler
```

Build the site and make it available on the local server

```
bundle exec jekyll serve
```

[Jekyll quickstart guide](https://jekyllrb.com/docs/)
